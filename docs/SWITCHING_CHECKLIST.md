# Switching checklist

For a church moving to Discuva from other tools. Go through it on the onboarding call.

## What replaces what

| Today | On Discuva | Note |
|-------|------------|------|
| Spreadsheets of members | Members, via member import | Clean the file first |
| Paper or form attendance | Check-in and attendance | |
| WhatsApp groups | Team spaces | Run both for a few weeks |
| Rota spreadsheets | Serving rota | |
| Giving records | Giving and finance | Decide a start date, and keep old records for reference |
| Bulk email or SMS tools | Announcements and notifications | |
| Call and meeting tools | Meetings with an outside link | Keep your tool. Built-in calls arrive in a later release |

## Before going live
- [ ] Two account owners added, with two-factor sign-in recommended
- [ ] Member file imported and spot-checked
- [ ] Services and venues added
- [ ] Departments and their heads added
- [ ] Other admins invited, with the right roles
- [ ] Notifications reviewed
- [ ] Member app link and QR code shared

## After going live
- [ ] Check first-week attendance against what you expected
- [ ] Decide when to stop using each old tool, usually when its contract ends
- [ ] Keep exports of old records
